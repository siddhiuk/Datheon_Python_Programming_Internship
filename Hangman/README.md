# Hangman Word Guessing Game

A terminal-based Hangman game built using Python. The player attempts to guess a randomly selected hidden English word, one letter at a time.

## Features

- Random word selection
- Masked word display
- ASCII gallows that updates with incorrect guesses
- Maximum of six incorrect guesses
- Previously guessed letter tracking
- Duplicate-guess protection
- Input validation
- Victory and defeat messages
- Option to play multiple rounds

## Requirements

- Python 3.10 or newer
- No external Python packages required

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run:

   `python hangman.py`

   On Windows, you can also use:

   `py hangman.py`

## Technologies Used

- Python 3

- Sets and strings
